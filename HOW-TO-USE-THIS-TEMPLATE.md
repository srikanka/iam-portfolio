# How to Use This Portfolio Template

This repository is a starting scaffold for your own IAM portfolio. The hard part,
the structure, is already done. You fill in your own work as you go.

## Steps

1. Create your own GitHub repository, for example iam-implementation-portfolio.
2. Copy these files into it: README.md, this guide, the screenshots folder, and the
   artifacts folder.
3. Open README.md and replace every [PLACEHOLDER] with your details.
4. As you build each capability in the course, fill in that section while it is fresh.
5. Save screenshots into /screenshots and config files into /artifacts, then update links.

## The rule that makes a portfolio work

This template is organized by CAPABILITY, not by course module, on purpose. An
interviewer scans for what you can do: onboard identities, provision, run the mover,
certify access, federate with OIDC, OAuth, and SAML. Lead with the capabilities you
can explain most confidently. You do not need every section filled before you start
applying.

## Before you commit anything public

Strip passwords, bind credentials, client secrets, and API keys from any config you
add to /artifacts. Replace them with REDACTED. A public portfolio must never leak a
real secret.
